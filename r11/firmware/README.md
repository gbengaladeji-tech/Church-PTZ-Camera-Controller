# R11 isolated bench firmware

Run `python -m unittest discover -s firmware -v` from the integration root. `main.py` initializes GP15 as a low output. `target.py` reads the actual 48-bit contact chain and three analog axes, emits local intents to REPL, and can update the Nextion after isolated supply and pin verification. The Sony-reference packet encoder is a pure host function. It has no physical port sender.

After the power checks and with all camera and LAN cables physically disconnected, import `target` on the matching W55RP20 MicroPython build and call `target.diagnostics(15)`. The pre-calibration log shows normalized raw axes and the local lock. Measure all nine values for the axis calibration and verify two witness bits in the 48-bit word. Call diagnostics with the recorded three calibration triples only after confirming the neutral wiring. A bench-only manual acknowledgement can be timed with `acknowledge_ms=1000`; keep all keys released and the stick centered from startup. Selection changes reset the neutral timer. The runtime has no path that enables the RS-422 drivers. R9's dummy-loopback and PIO examples are retained in the preserved R9 draft for a later isolated transport qualification.

Faults latch for malformed analog calibration, invalid axes, failed scan witnesses, stale scans, unsupported camera selections and simulated link faults. Acknowledgement requires a fresh neutral interval and releases any previous selection. The witness detects open/stuck rails and common scan-chain loss. It is a diagnostic and can miss faults that mimic the expected pattern. A logged STOP records an intent. Remote stop delivery cannot be assured when the cable or remote unit loses power.
